# Bolbol TV (bolboljan-androidtv)

A private, fast, TV-native Android TV client for Bolboljan: Persian RTL UI, Continue Watching,
resume, auto-next, account sync, voice search and a phone/QR remote. Built for a Xiaomi Mi TV P1 43".
